# Parchment

A collection of Typst templates designed for English and Traditional Chinese

## Installation

Install this collection as local Typst packages with one command:

```sh
curl -fsSL https://raw.githubusercontent.com/chen1plus/parchment/main/install.sh | bash
```

### Development

`install.sh` is generated from `install-src.sh` with [argc](https://github.com/sigoden/argc)

```sh
argc --argc-build install-src.sh install.sh
```
